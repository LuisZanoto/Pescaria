No jogo de pescaria é tipo browser, ele carrega algumas telas e controla um barco navegando em mapas.
Tem a opção de guardar configurações no celular de quem acessa o site do jogo 
( esta opção deve ficar na parte superior junto com algumas informações, no campo salvar ),
 como por exemplo algumas opções do jogo, como Saldo atual em dinheiro,
 tempo jogado, iscas atuais, anzois armados, peixes pegos (kg), peixes vendidos (kg), etc. 
Fazer isso sem criar contas e sem login.
 Simplesmente ele pressiona o botão de configurações , abre uma janela com os itens 
que ele for conquistando e salva no proprio celular como algum arquivo tipo Json.
 Quando ele retorna ao jogo, pode recuperar as informações salvas no celular dele. 
 Alertar para não usar modo anonimo ou outro navegador para não perder dados.
 
 // Exemplo do objeto salvo em localStorage
let dadosDoJogo = {
    dinheiroGasto: 450.50,
    tuviras: 20,
    piaus: 5,
    anzoisArmados: 0,
    iscaPega: 0,
    peixePegoKg: 0,
    peixeVendidoKg: 0,
    valorPeixePorKg: 30,
    gasolinaAtualLitros: 10,
    iscasArmadas: [],
    tempoJogadoMinutos: 0,
    estatisticas: {
        saldoPescaria: (30 * 0) - 450.50,
    }
};

function salvarProgresso() {
    // JSON.stringify transforma o objeto em uma string JSON
    localStorage.setItem("pescariaGameSave", JSON.stringify(dadosDoJogo));
    console.log("Progresso salvo com sucesso no celular!");
}

// Exemplo para recuperar os dados:

let dadosDoJogo = {};

function carregarProgresso() {
    let saveSalvo = localStorage.getItem("pescariaGameSave");
    
    if (saveSalvo) {
        // Converte a string JSON de volta para um objeto JavaScript
        dadosDoJogo = JSON.parse(saveSalvo);
        console.log("Save carregado com sucesso!");
    } else {
        // Valores iniciais caso seja o primeiro acesso
        dadosDoJogo = {
			dinheiroGasto: 450.50,
			tuviras: 20,
			piaus: 5,
			anzoisArmados: 0,
			iscaPega: 0,
			peixePegoKg: 0,
			peixeVendidoKg: 0,
			valorPeixePorKg: 30,
			gasolinaAtualLitros: 10,
			iscasArmadas: [],
			tempoJogadoMinutos: 0,
			estatisticas: {
				tempoJogadoMinutos: 0,
				saldoPescaria: (30 * 0) - 450.50,
			}
        };
        console.log("Nenhum save encontrado. Iniciando novo jogo.");
    }
}

// Chame essa função assim que o jogo carregar
carregarProgresso();


Observações :
- dar a opção de recuperar dados do jogo.
- atualizar este arquivo ( Jogo.txt ) conforme o jogo cresce e aumenta as possibilidades e opções.
- manter estatísticas, saldos e opções de salvamento ocultos no botão "Salvar_Dados".
- exibir as estatísticas e os saldos somente quando o jogador pressionar o botão "Salvar_Dados";
oferecer nesse painel as ações de salvar e recuperar o progresso.
- o botão "Salvar_Dados" deve iniciar fechado, somente quando usuário clicar que vai aparecer as estatisticas e dados do jogo.
- tempoJogadoMinutos é atualizado conforme passa o tempo do jogo ( minutos).
- O motor gasta 1 Litro de gasolina por km rodado subindo o rio e 0,5 Litros por km rodado descendo o rio, independente da velocidade.
quando tiver acabando gasolina (2 litros ou menos), avisar com texto simples na tela e dar opção de compra e atualizar gastos, sendo R$6,50 cada litro de gasolina comprado.
- Criar um outro botão de "Armar isca" e liberar o uso somente quando o barco estiver parado e em alguma margem do rio.
- O botão de armar isca vai abrir uma possibilidade de comprar tuviras e piaus, sendo R$5,00 a tuvira e R$10,00 piaus.
Deverá ser acrescido nos gastos a soma de piaus e tuviras comprados e deve ser atualizado o saldo das mesmas.
Quando armar isca, memorizar o local onde foi armado com uma bandeirinha amarela na margem do rio onde foi armado e atualizar o saldo subtraindo tuviras ou piaus.
- As compras de gasolina e iscas são contabilizadas em dinheiroGasto; o saldo é calculado como (peixeVendidoKg * valorPeixePorKg) - dinheiroGasto.
- Os locais das iscas armadas são mantidos em iscasArmadas no salvamento para que as bandeirinhas reapareçam ao recuperar o progresso. Caso o gamer quiser,
ele pode chegar perto da bandeirinha e desarmar a mesma, se quiser armar em outro local, porém as iscas são perdidas.
